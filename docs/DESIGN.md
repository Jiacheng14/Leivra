# UI 与交互设计
采用暖白、鼠尾草绿和低饱和灰；深色为墨绿背景。借鉴常见即时通讯的布局习惯，不使用微信品牌或素材。

桌面：左侧品牌与单一会话入口，右侧头像/角色标题、聊天记录和底部输入区。侧栏是当前会话展示，不制造未实现的联系人入口。700px 以下隐藏侧栏。全屏采用 100dvh 和安全区域内边距；桌面最大宽 1320px。

角色默认头像为自绘 SVG 插画，用户头像为中性剪影。角色配置独立，可替换素材；自定义上传尚未实现。
用户气泡右对齐绿色，角色气泡左对齐白色/深色表面。文本原样渲染，不解析 HTML 或 Markdown。
模拟回复可拆成独立气泡；使用短暂输入指示，不含小说式旁白。

桌面 Enter 发送、Shift+Enter 换行；IME 组合输入期间不发送。触屏回车换行，按钮发送。空白禁发，2000 字符上限，单次请求串行。
阅读旧消息时不自动拉到底部；发送新消息后回到底部。
设置使用原生模态 dialog，支持 Escape、焦点约束及关闭后焦点恢复。
图标按钮有可访问名称，消息区采用 log，动效尊重 prefers-reduced-motion。
清空二次确认，并中断挂起的回复；导出当前本地消息 JSON。

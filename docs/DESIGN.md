# UI 与交互设计
采用暖白、鼠尾草绿和低饱和灰；深色为墨绿背景。借鉴常见即时通讯的布局习惯，不使用微信品牌或素材。

桌面：左侧品牌与联系人列表，右侧头像/角色标题、聊天记录和底部输入区。侧栏复用原有会话样式，点击联系人切换其独立会话。700px 以下侧栏默认收起，通过标题栏联系人按钮打开同一侧栏。全屏采用 100dvh 和安全区域内边距；桌面最大宽 1320px。

角色默认头像为自绘 SVG 插画，用户头像为中性剪影。人物卡独立，可替换素材；自定义上传尚未实现。
用户气泡右对齐绿色，角色气泡左对齐白色/深色表面。文本原样渲染，不解析 HTML 或 Markdown。
模型结构化输出对应独立气泡；使用短暂输入指示，不含小说式旁白。

桌面 Enter 发送、Shift+Enter 换行；IME 组合输入期间不发送。触屏回车换行，按钮发送。空白禁发，用户输入 2000 字符上限；每会话生成串行，但输入和发送在生成/派发期间仍可用。
阅读旧消息时不自动拉到底部；发送新消息后回到底部。
设置使用原生模态 dialog，支持 Escape、焦点约束及关闭后焦点恢复。
图标按钮有可访问名称，消息区采用 log，动效尊重 prefers-reduced-motion。
清空二次确认，并中断挂起的回复；导出当前本地消息 JSON。
界面文案精简：移除聊天区欢迎装饰、侧栏抒情文案、在线标题副文案及顶部模拟提示栏，不保留占位。标题栏收紧为桌面 72px、手机 64px，聊天区直接呈现日期和消息。品牌标语统一为用户指定的「我的目光永远注视着你」，同步页面与 PWA 描述。「本地原型」标识、设置中的模拟回复和存储说明保留；原有离线状态说明、其他文案及聊天行为不变。

2026-10-27：沿用现有聊天视觉。联系人侧栏显示头像和名称，提供添加、选择与逐项删除；设置内折叠的人物卡入口仅保留编辑和导出，不增加管理页面。手机打开同一侧栏进行联系人操作。角色名称、头像、输入占位和可访问标签来自当前卡片；长名称截断。清空与聊天导出作用于当前角色。


删除确认明确指出人物卡、专属会话、消息及默认角色旧版备份的范围，默认焦点落在取消按钮。取消不改数据；确认删除后移除当前联系人时选择剩余联系人。删空后只显示「暂无联系人」，隐藏无目标输入区，保留侧栏添加入口。手机侧栏使用原生模态抽屉，选择/成功添加后收起，可关闭或按 Escape 返回聊天。


## 自然聊天阶段
沿用现有布局、颜色、头像、联系人入口和主题。回复等待时间滑条默认 5 秒、每档 1 秒；其下方的最大等待时间滑块末端为“不限”。输入延后仍使用现有复选框。收集期间不假装模型正在输入；生成/派发期间复用现有输入指示。API 失败在原错误区域提示，并提供“重试回复”，不显示上游原始错误。只有模式切换提示提供 X，忽略的消息在原气泡旁显示红色感叹号。

每个已发送用户消息保留独立气泡；回复由模型给出的数组决定气泡边界，第一条直接显示、后续延迟 1–4 秒。长段落正常换行，不逐字渲染。切换联系人时原会话后台继续；手机使用同一侧栏。

Mock 保留现有模拟与本地存储说明。Real 的设置、底部隐私说明和离线提示明确表示上下文经本机后端发送至 OpenAI、实际调用可能计费，避免继续显示“不会上传”的不实说明。没有额外宣传语或模型管理页面。

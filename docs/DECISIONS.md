# 产品与技术决策
日期：2026-10-26（用户时区）

## 已确定
1. 项目名 Leivra（蕾芙菈），目录按用户指定 D:\GCHYL\GAME\Leivra，包名 leivra。
2. 第一阶段仅本地原型，不部署、不调用真实模型、不实现记忆/推送/语音。
3. React + TypeScript + Vite + Tailwind v4 + vite-plugin-pwa；使用 pnpm 锁定依赖。
4. 本机有 Codex 自带 Node/pnpm、无系统 npm。提供启动脚本，依赖布局使用 hoisted 兼容 Windows，pnpm 配置保存在 pnpm-workspace.yaml。
5. 通用聊天风格为自然即时消息，不使用小说旁白；温柔成熟等性格仅属于默认蕾芙菈人物卡。
6. localStorage 仅为原型临时存储，最多 500 条、单条 2000 字符，未加密。明确提示限制，提供导出与确认清空。
7. 默认原创 SVG 头像，可替换配置；不引入外部素材与付费服务。
8. PWA 生产模式缓存应用壳，更新须用户点击刷新，避免输入时自动刷新。

## 计划中
Cloudflare Pages + Workers + D1；后端模型适配层；身份验证与云端数据操作。上线前再次确认费用与部署授权。

## 待讨论
模型、成本上限、身份认证、记忆策略、主动消息边界、通知权限、语音供应商和角色上传体验。
## 2026-10-27：人格系统解耦
- Leivra 调整为通用 AI 人格聊天应用，蕾芙菈是首个默认联系人。群聊暂不实现。
- 独立实现 Leivra 自有 v1 JSON，不引入 Coopanion 代码、AGPL 依赖或复杂第三方卡片格式；本阶段无新增依赖。
- 人物卡 schemaVersion 管格式、revision 管编辑版本、id 管长期关联。导入重复 ID 拒绝，编辑保留 ID。
- 本地统一快照 leivra.data.v1，当前每角色一条私聊；老键只在新快照不存在时迁移，成功后保留迁移备份，清空默认角色时移除备份。
- 人格不能变更唯一 system 通用协议；未来供应商适配必须保持此优先级，不能把全部内容拼为同级指令。
- 共享信息只接受明确授权；记忆按角色及版本筛选。当前发送不注入任何共享资料或记忆。
- 仅新增最小设置入口并复用侧栏；Mock 保留默认角色的原有示例与回复，其他导入卡不生成欢迎语，使用固定中性测试回复。
- 群聊、真实模型、记忆提取、主动消息、语音、云环境均未实施。


## 2026-10-27：联系人管理入口统一
- 联系人操作归侧栏，手机通过标题栏入口打开同一侧栏；设置只保留当前人物卡编辑和导出。
- 添加复用 Leivra v1 导入，卡片格式与 ID 关联不变。删除需要确认范围，取消请求后移除专属本地数据。
- 内部快照允许 activeCharacterId=null 的空联系人集合，持久化而不重新初始化默认角色；不升级或更改人物卡 schema。
- 删除当前联系人选择列表第一名剩余联系人；删空后保留添加入口。


## 2026-10-27：自然调度与本机模型接入
- 按本次授权实现最小 Workers 后端及 OpenAI Responses 适配；没有配置真实密钥、没有付费请求、没有正式部署。此前“仅 Mock/未接入”的条目描述对应历史阶段。
- 默认依旧 Mock；Real 由启动命令选择，模型名在后端配置，不增加模型管理 UI。新增 Wrangler 仅用于本地 Workers 开发；不引入 SDK、Coopanion 或 AGPL 代码。
- 3.5 秒静默收集，1–60 秒可调；输入延后默认关闭，开启后按同一等待时间计算输入静默期。此阶段每轮从第一条已发送消息起最多等待 5 分钟。待处理队列是已发送消息，绝不上传草稿。

## 2026-10-28：模式切换任务忽略与最大等待
- 模式切换后的待回复任务可由用户忽略；仅目标会话的任务被清空，消息保留并标记，后续模型上下文排除已忽略消息。已生成内容继续按派发游标显示；忽略状态须先持久化成功。
- 最大等待时间默认 5 分钟，可设为 1–10 分钟（步长 0.5）或“不限”；JSON null 表示“不限”，旧设置缺失此字段时沿用 5 分钟。
- 角色切换继续原请求；清空/删除取消目标请求。每会话串行，多会话独立，超时或失败不自动重试、不退回 Mock。
- 解除原 1–8 条/2000 字 AI 输出限制，保留异常安全上限 32 条/单条 32000/合计 64000 字符。卡片旧 maxReplyMessages 仍可导入导出但不再限制输出；不修改默认人格。
- 第一气泡立即显示，后续使用独立平方根延迟函数。消息和发送游标同快照保存，刷新不中断已生成内容的继续显示，也不自动重放未完成请求。
- 本机 Real 绑定 loopback、限制 Origin 和请求类型；没有认证，因此不提供局域网/公网 Real 服务。内存限流不是生产配额或费用保证。
- 本地快照添加可选设置/调度字段，旧数据直接兼容；人物卡 schemaVersion 与稳定 ID 不变。
- 自动测试只使用 Mock/伪造上游/强制无密钥的测试 Worker。真实模型冒烟由用户配置后在页面显式操作，普通测试永远不发付费请求。

## 2026-10-28：Persona Engine 第一阶段
- 保留 Leivra v1 和现有消息调度；V2 是可选完整源文档加校验投影，不执行破坏性数据迁移。
- 仅承诺 V2 JSON 数据兼容。未知字段和扩展原样保存；系统提示词替换、历史后注入、世界书、自动开场白和思考控制不实现。
- 固定应用协议拥有最高应用指令权限，PersonaRenderer 只产生低信任资料 JSON；不通过关键词删除或改写用户人格文本来声称消除提示词注入。
- 默认卡从 TS 精确迁移至 JSON；原卡基准与六类固定场景作为测试素材，不作为生产联系人或聊天记录。
- 自动测试只验证数据、请求边界与恢复，不能证明真实人格表现；模型行为对照须另行获得用户授权。
- 先前 P0（Vite 可访问后端密钥文件）已有 bda5f0b 修复，本次用假密钥再次验证拒绝访问。未读取真实密钥。

## 2026-10-29：IndexedDB 与本地备份

- 保留 v1 人物卡、会话和消息模型；IndexedDB v1 以单个版本化快照作原子提交，避免消息、设置和调度游标跨多个事务失配。消息数组顺序为权威顺序；不再截断 500 条历史。
- 仅在 IndexedDB 无 current 时迁移原 localStorage 快照，验证提交后数据一致；旧键保留且停止实时写入。有效 IndexedDB 数据不被旧键覆盖。
- Web Locks 继续限定单页写入和生成；异步写入按队列串行，生成状态提交完成前不得调用模型。
- JSON 备份采用版本 1，完整替换恢复。恢复事务保留替换前原值并写入新值，读取校验后重新启动调度；不自动重发结果未知的请求。备份只含应用数据，不含服务端密钥。
